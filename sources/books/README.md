# Your library goes here (local only)

This folder is intentionally empty in the public repo. The books ZenMillionaire
cites are copyrighted, so their full texts are not distributed here.

To deepen the skill with a source you own:

1. Buy the book.
2. Drop your PDF in this folder (e.g. `psychology-of-money.pdf`).
3. Run the **Add a source** task (`tasks/add-source.md`). The skill distills it
   into a cited framework under `frameworks/` and registers it in
   `sources/INDEX.md`.

Anything you place here is git-ignored, so your local library never gets pushed.
See `sources/INDEX.md` for the full list of sources the frameworks already cover.
